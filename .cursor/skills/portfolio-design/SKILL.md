# Portfolio Design Skill

When generating portfolios, follow these principles to create distinctive, professional landing pages.

## Core Principles

1. **One cohesive direction** — Pick a single design language and commit to it
2. **Role-aware** — Match visual style to the user's profession (developer, designer, PM, creative)
3. **Content-first** — Typography and layout serve the work, not the other way around
4. **Restraint** — Less is more; avoid visual noise

## Process

1. Analyze user's title, skills, and projects
2. Select palette + layout variant from skill files
3. Generate design tokens (colors, fonts, layout)
4. Write section content that is specific to the user's actual work

## Output

Always output structured design tokens + section content. Never output raw HTML.
