# Layout Patterns

## Hero Variants

### split
Two-column: text left, visual element right. Good for developers and designers with strong visual identity.

### centered
Single column, centered text. Good for minimal and editorial styles.

### minimal
Small headline, lots of whitespace. Good for senior professionals.

## Project Grid Styles

### bento
Asymmetric grid — first project spans 2 columns. Creates visual interest. Best for designers and creatives.

### classic
Uniform 2-column card grid. Clean and scannable. Best for developers.

### editorial
Full-width project rows with large images/text. Magazine feel. Best for writers, PMs.

### terminal
Monospace accents, command-line inspired labels (`> project_name`). Best for backend/devops engineers.

## Section Order

Default: Hero → Projects → Skills → Contact

For designers: Hero → Featured Work (projects) → Skills → Contact

For developers: Hero → Skills → Projects → Contact
