# Typography Guidelines

## Font Pairings (pick one pair per portfolio)

| Role | Heading | Body |
|------|---------|------|
| Developer | JetBrains Mono / Space Grotesk | DM Sans / Geist |
| Designer | Playfair Display | Inter / DM Sans |
| Creative | Clash Display / Syne | Work Sans |
| Minimal | Geist | Geist |
| Editorial | Playfair Display | Source Serif |

## Type Scale

- Hero headline: 3rem–5rem (clamp for responsive)
- Section titles: 1.5rem–2rem
- Body: 1rem, line-height 1.6–1.75
- Small/captions: 0.875rem

## Rules

- Never use only Inter with no character
- Limit to 2 font families max
- Use font-weight contrast (bold headings, regular body)
- Generous letter-spacing on uppercase labels only
